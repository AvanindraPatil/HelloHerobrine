## Requirements

- **Hello Neighbor** on Steam, on Windows.
- Nothing else: the installer brings [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) (the mod loader).

## Install

1. Download `HelloHerobrine-1.0.1.zip` from [Releases](../../releases), unzip it anywhere and keep the folder until you
   uninstall.
2. Close Hello Neighbor, then double-click **`Install.bat`**. It finds the game through Steam (or asks for its folder).
   - Windows may warn about running a script from the internet. Choose "More info", then "Run anyway".
3. Start Hello Neighbor from Steam as usual and pick **New Game**.

No game file is changed: it adds UE4SS (unless you already have it) and the mod.

## Keys

| Key | |
|---|---|
| F9 | the mod on / off (off = the normal Neighbor; not on the main menu) |

Everything else uses the game's own keys.

## Uninstall

Double-click **`Uninstall.bat`**. It removes the mod, and UE4SS too if this mod installed it.

## Trouble?

- Other mods that change the Neighbor (Hello Playtime, Tom & Jerry, Hello Nicky, ...) fight with this one: use one at
  a time.
- Logs: `<Hello Neighbor>\HelloNeighbor\Binaries\Win64\herobrine_lua.log` and `ue4ss\UE4SS.log` in the same folder.
